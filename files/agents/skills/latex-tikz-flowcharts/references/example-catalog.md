# Flowchart example catalog

These PDFs are visual references for composition, hierarchy, typography, grouping, and annotation.
Inspect the most relevant examples before creating a new diagram.
Do not copy their domain content into unrelated work.

## `bitemporal-mirror.pdf`

Use this reference for a transformation system that combines a main processing path, auxiliary inputs, a persistent output store, and a compact comparison table.
It demonstrates how to separate an always-running mirror from an optional rules stage while keeping the main story visible.

## `rule-curation-ui.pdf`

Use this reference for a lifecycle, feedback loop, or human-in-the-loop workflow.
It demonstrates a strong central sequence, supporting automation above and below it, and long return paths that remain visually distinguishable.

## `ui-tech-stack.pdf`

Use this reference for a small deployment or runtime architecture with multiple execution contexts.
It demonstrates a bounded cloud region, local development tools, source control, and a headless job without overloading the page.

## `entity-asof-view.pdf`

Use this reference for a long left-to-right data pipeline.
It demonstrates how to present sequential transformations, a source data store, an analytical inset, and a terminal validation stage on a wide canvas.

## `pseudonymized-zone.pdf`

Use this reference for trust boundaries, data zones, privacy architecture, or controlled exceptions.
It demonstrates two large bounded regions, a projection between them, differentiated data stores, and a policy-steered exceptional path.
